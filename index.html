Nomos is a community-maintained mapping from vendor and product names, as they appear across disparate security data sources, to a single canonical identity per vendor and per product.

Search the live index View on GitHub

Every source names things differently

NVD CPE microsoft:windows_server nvd
endoflife.date windows-server endoflife
CISA KEV Microsoft Corporation cisa_kev
OSV pytorch (PyPI) osv

Data model

Vendor
data/vendors/<id>/vendor.yaml
Stable id, display name, source aliases.
Product
data/vendors/<id>/products/<id>.yaml
Type, tags, optional services, aliases.
Alias
{source, value, confidence}
curated = human-verified; auto = unverified match.
Service
{protocol, port, name, default}
Optional, product-level — the network services a product exposes (software/appliance/os types only).
Tag
data/taxonomy/tags.yaml
The closed set of category labels.
